## 首要待解决问题

1. **菜单中的删除文件项没有产生预期结果。** `tests/event-drawer.spec.ts` 的第二个测试，点击首个文件项菜单“删除文件项”后仍为 2 项，预期 1 项。不是已确认的服务层错误。优先复现 `ActionMenu.vue` 的点击、滚动关闭、focusout 与 slot 事件时序；核实确认对话框是否真正出现、是否调用了 removeItem 与 IPC。不要只放宽断言。
2. **菜单导入模板未完成。** `tests/ui-redesign.spec.ts` 第二个测试，选择本地 txt 文件并点击“导入模板”后，列表仍显示“未导入”，预期“可用”。可能与菜单公共事件路径有关，但根因未确定。需核实菜单事件、原生选择器以及 importLibraryFile 调用。
3. **复制项目路径未读到结果。** 新 UI 测试点击复制后立即读取 Electron 剪贴板得到空字符串。实现使用 `navigator.clipboard.writeText`。先区分异步等待和 file 协议权限问题；可以先用 `expect.poll` 验证时序。若浏览器 API 在打包场景不可用，再考虑最小且受校验的 preload 接口，并同步测试接口集合。不能仅删掉复制功能或测试。
4. **旧测试定位不精确。** `tests/pending-filters.spec.ts` 使用 `getByRole('button', { name: '清除' })` 同时匹配“清除”和“清除筛选”，需要按实际按钮使用 `exact: true` 或明确作用域。这一项目前属于测试定位问题。

具体失败输出与行号见 `evidence/checkpoint-e2e.txt`。第 3 个失败导致六类弹窗和窄窗口综合测试只运行到项目详情复制步骤，后面的事项、文件项、待办弹窗及窄窗口截图尚未全部实际验证。
