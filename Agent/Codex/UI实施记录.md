# WorkPack UI 改版

基线：origin/main，2188e8a。分支：codex/warm-ui-reproduction。

以 UI精简版 中用户确认的五张图片为依据。追加项目列表、事项抽屉及六类弹窗设计后再实现这些页面。生成的抽屉参考背景仍含旧说明，实际实现采用精简项目详情，不恢复已删除文案。

## 验收范围

- 暖白画布、全高侧栏、陶土色操作、宋体标题及简洁正文；移除冷灰蓝浮动壳层。
- 工作台、项目列表、项目详情、待处理、文件库、存储设置，包括空状态及真实数据。
- 六类创建及编辑弹窗、事项抽屉、文件待办与附件、菜单、搜索、错误及迁移提示。
- 删除用户圈出的说明，保留用户数据、必要错误及迁移提醒。无虚构可点击入口。
- 匹配图片的状态标签必须真实过滤文件的完成情况，已完成不能是永远为空的选项。
- 保留导入、导出、附件重新定位、分类管理、删除确认、焦点恢复和存储变更。
- 对照真实渲染截图，检查最小窗口、键盘、长名称、失效文件、所有操作。
- 单元测试、静态检查、构建、端到端、设计规范校验；检查旧颜色、旧结构、无效引用。
- 提交 commit 与 PR，检查远端 diff 和 CI，自审记录问题及修复。

## 当前进展

已完成暖色 UI 接续实现与自审。原四项 E2E 失败已解决，补齐三种窗口、六类表单、旧多附件菜单、失效路径、焦点恢复与保存状态回归，并移除未使用依赖和修复构建依赖漏洞。
