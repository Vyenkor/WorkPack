更新时间：2026-11-08。

## 本期目标

形成“创建或导入项目 → 创建或导入事项 → 选择模板 → 上传产出版本 → 跟踪日期和紧急程度 → 集中查阅和导出”的完整流程。

Linear 是可选数据来源。本地项目、事项和文件管理独立可用。文件准备、签字、盖章及归档情况由用户确认。

- 项目界面遵循根目录 [DESIGN.md](../../../DESIGN.md)，运行和测试方法见[开发指南](../../../docs/DEVELOPMENT.md)。
