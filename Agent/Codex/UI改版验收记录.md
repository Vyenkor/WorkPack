# UI 改版验收记录

## 2026年11月7日 · Linear 浅色桌面版

本轮按用户提供的 Linear 浅色应用截图更新工作台、项目列表、项目详情、待处理、文件库、设置、事项抽屉及六类表单。工作台直接展示待处理文件和最近项目，项目列表按列对齐，窗口采用灰白面板与蓝紫色操作。左下角单独显示灰度图形标。

顶栏提供侧栏折叠、返回和前进，展开及折叠时工具与当前位置文字始终处于同一高度。折叠后主面板左右外边距均为 8px。页面导航支持主页面及具体项目，支持 Alt+←、Alt+→，保留当前筛选并跳过已删除项目。返回后进入其他页面会开始新的前进分支。

底部统一预留 40px 留白区，主面板在小标上方结束。小标位于窗口左下方，距左侧 24px，并在底部区域内垂直居中。展开及折叠使用相同的留白和图标位置。

英文和数字使用随应用打包的 Inter Variable 4.1，来源为 Linear 公开字体资源。正文采用 15px、450 字重，辅助文字及按钮 13px，标签 12px。字体栈和字号参考 [Linear 应用样式](https://static.linear.app/client/assets/style-nDwjYmzh.css)。在本机 Electron 中检查实际字形，英文为 Inter Variable，中文按该字体栈回退为 Noto Sans SC，切换英文及简体中文语言标记得到相同中文字体。Inter 的 OFL 许可随构建产物保存。

- 类型检查及生产构建通过，生成的 renderer 包含 Inter 字体及许可文件。
- Vitest 23 项通过。Python 运行 77 项，3 项按环境跳过，其余通过。
- Electron 端到端运行 16 项，15 项通过。安装后应用测试按条件跳过，由 Windows CI 运行。
- 验证 1600×1000、1280×800、1050×700，覆盖全部主页面、六类弹窗、抽屉、长名称、路径复制、菜单、文件导入导出及状态筛选。
- 新增当前导航标识、顶栏对齐、折叠后对称边距、底部图标位置、项目列对齐、本地 Inter 实际加载和工作台抽屉编辑返回的验证。
