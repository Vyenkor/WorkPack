# 使用 WorkPack

## 安装与卸载

从 [GitHub Releases](https://github.com/Vyenkor/WorkPack/releases/latest) 下载 Windows x64 安装包 `WorkPack-<版本>-Setup.exe`。

安装向导支持选择当前用户或所有用户、安装目录，以及是否创建桌面快捷方式。开始菜单快捷方式会自动创建。安装包目前没有代码签名；首次运行时如遇 Windows SmartScreen 提示，可核对下载来源后，选择“更多信息”继续运行。

卸载可使用 Windows 设置中的“应用”，也可运行安装目录内的 `Uninstall WorkPack.exe`。卸载向导默认保留工作空间记录；勾选“删除工作空间记录”时，只清理默认系统目录中的数据库及设置。项目文件、模板原件和自选位置的数据继续保留。

## 建立一套项目资料

1. 在**文件库**添加模板，填写名称和用途，按需导入原件并选择分类。
2. 新建项目，填写客户和负责人。WorkPack 会在项目存储位置下创建同名文件夹。
3. 在项目中创建业务事项，选择需要的模板。每份模板生成独立文件项，已有模板原件会复制到事项目录。
4. 每份文件默认有“准备文件”待办。先上传或使用已有工作副本，再勾选完成；其他待办可自行添加。

同一模板用于不同事项时，各事项的文件和待办分别管理。

## 查看与跟进

- **工作台**显示待处理文件和最近项目。点击文件行打开对应事项，点击项目进入详情。
- **项目**按客户、负责人、事项数量和资料进度展示，可搜索并按完成状态筛选。
- **待处理**默认显示未完成文件，可切换全部或已完成，按项目、客户、经办人筛选，并按项目或经办人分组。清除筛选恢复未完成，主动选择的筛选会保留。
- **文件库**支持名称与文件名搜索、分类筛选、导入原件及导出。原件失效时会显示状态。

顶部搜索可查找项目、事项与文件名称。`Ctrl+K` 聚焦搜索，`Alt+←` 返回，`Alt+→` 前进。左上角按钮可折叠侧栏。工作空间菜单中的 **News** 展示最近更新，**设置**打开存储设置。

事项抽屉和表单支持键盘操作。下拉选择器展开时，`Esc` 先收起下拉层；再次按下才处理表单关闭。有未保存修改时会确认，保存或上传期间会保留窗口。

## 存储与迁移

在**设置 → 存储**中分别管理三个位置：

| 内容 | 默认位置 |
| --- | --- |
| 工作空间数据库 `workpack-v3.sqlite` 及设置指针 | Electron 应用数据目录，Windows 下通常为 `%APPDATA%\WorkPack` |
| 模板原件 | 应用数据目录下的 `templates` |
| 项目目录、工作副本和附件 | 文档目录下的 `WorkPack\项目\<项目名称>` |

更改模板或工作空间数据位置时，应用会复制当前数据，成功后切换，原目录保留。数据库复制由当前连接生成一致副本。模板迁移使用同卷硬链接安全落位；目标文件系统不支持时会停止迁移并保留原位置。迁回原工作空间目录前，按设置中的迁移说明处理旧数据库及其 `-wal`、`-shm` 文件。

项目目录移动后，可以在项目详情中重新定位。项目文件夹包含 `.workpack-project.json` 标记，事项工作副本位于 `事项/<日期>_<事项ID>/<文件项ID>` 下。

备份前退出 WorkPack，保存工作空间数据目录、模板目录和项目目录。旧版 `workpack.sqlite` 保留原样，新版使用独立的 `workpack-v3.sqlite`。

## 删除时如何处理文件

| 操作 | 实际文件的处理 |
| --- | --- |
| 删除项目记录 | 保留项目文件夹及其中的文件 |
| 移除附件记录 | 保留原文件 |
| 移除模板文件记录 | 保留原文件，解除记录关联 |
| 删除业务事项 | 删除该事项目录及其中的工作副本和附件 |

执行删除操作时，按确认提示核对对象。
