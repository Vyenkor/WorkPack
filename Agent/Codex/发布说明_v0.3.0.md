# WorkPack v0.3.0

本次更新重新整理了工作区界面，让项目、事项和文件的跟进更集中。

## 新界面与导航

- 浅色工作区、紧凑侧栏和统一的中英文字体，列表与操作区保持对齐。
- 支持折叠侧栏、返回与前进，快捷键为 `Alt+←` 和 `Alt+→`。
- 工作空间菜单提供 News 与设置，更新日志放在二级页面。
- 程序、任务栏、安装及卸载图标统一为灰色，窗口标题精简为 WorkPack。

## 文件跟进

- 工作台集中展示待处理文件和最近项目，点击文件可直接打开事项抽屉。
- 文件库支持搜索和分类筛选，事项中的文件拥有独立待办。
- 待处理默认显示未完成文件，保留主动选择的筛选和分组。
- 存储设置提供路径复制及迁移说明。

## 修复

- 上传等操作进行中，Esc、返回和遮罩均保留事项抽屉。
- 筛选偏好保存失败后，继续保存排队中的最新修改。
- 分类下拉展开时，Esc 先收起选择器，再处理弹窗关闭。
